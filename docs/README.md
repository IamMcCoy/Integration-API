# 문서

이 디렉토리는 코드가 담지 못하는 것 — **왜 이렇게 만들었는가** — 를 남기는 곳이다.
코드를 읽으면 알 수 있는 내용(무엇을 하는가)은 여기 쓰지 않는다.

## 지도

| 위치 | 무엇을 쓰나 | 언제 쓰나 |
|---|---|---|
| [`overview.md`](overview.md) | 프로젝트가 무엇이고 무엇이 아닌지 | 범위가 바뀔 때 |
| [`architecture/`](architecture/) | 계층 구조, 데이터 흐름, 배포 형태 | 구조가 바뀔 때 |
| [`design/`](design/) | 파이프라인·API·DB 설계, 코드 규칙 | 설계를 정하거나 바꿀 때 |
| [`adr/`](adr/) | 되돌리기 비싼 결정과 그 이유 | 대안을 놓고 하나를 골랐을 때 |
| [`experiments/`](experiments/) | 실제로 돌려본 것과 그 결과 | 가정을 검증했을 때 |

## 쓰는 기준

- **ADR** — 나중에 누군가 "왜 X 안 쓰고 Y 썼지?" 하고 물을 만한 결정. 되돌리는 데 비용이 드는 것만. 라이브러리 선택, 저장소 선택, 경계를 어디에 그었는지.
- **실험** — 문서에 "아마 이럴 것이다" 라고 쓰고 싶어질 때. 그러지 말고 돌려보고 결과를 기록한다. 재현 방법을 반드시 포함한다.
- **설계** — 여러 파일에 걸쳐 있어서 한 파일만 읽어서는 안 보이는 흐름.

새 ADR 은 [`adr/template.md`](adr/template.md) 를 복사해서 시작한다.
