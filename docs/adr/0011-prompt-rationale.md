# ADR-0011: 프롬프트에 지시와 함께 이유를 적는다

- **상태:** Accepted
- **날짜:** 2026-08-07

## 배경

[ADR-0009](0009-filter-model-and-prompt.md) 에서 선별 프롬프트를 영어로 바꿔 토큰을
15% 줄였다. 그때 추출·식별은 "검증하지 않은 건 안 건드린다" 는 이유로 한국어로 남겼다.

추출 실험([ADR-0010](0010-extraction-verification-and-merge.md))을 마친 뒤 토큰 비중을
재보니 추출 프롬프트가 **한 요청의 55%** 였다(347토큰 vs 청크 본문 281토큰). 선별이
20% 였던 것과 비교하면 훨씬 큰 자리다.

## 선택지

**A. 한국어 유지.** 대상 문서가 한국어이고 `evidence` 는 그 원문을 글자 그대로 옮기는
일이라, 지시 언어를 맞추는 편이 안전하다는 논리.

**B. 영어로 번역.** 선별에서 통한 방식을 그대로 적용.

실측하니 B 가 명확히 나빴다 — 3회 모두 적중 18~19 로, 한국어 원본의 21~22 에 못 미쳤다.
여기서 A 로 결론 낼 뻔했다.

**그런데 변형을 둘 더 만들어 보니 원인이 언어가 아니었다.**

| 변형 | 적중 | 파라미터 | 프롬프트 토큰 |
|---|---|---|---|
| ko (원본) | 23/24 | 147 | 347 |
| ko-tight (한국어에서 이유·예시만 제거) | **18/24** | 126 | 202 |
| en (1판 번역) | **18/24** | 122 | 230 |
| **en2 (영어 + 이유 보강)** | **23/24** | **157** | **196** |

`ko-tight` 이 `en` 1판과 **정확히 같은 18/24** 로 떨어졌다. 언어가 원인이면 한국어
압축본은 안 떨어졌어야 한다. 둘의 공통점은 하나 — 이유 설명과 예시를 걷어냈다는 것.

## 결정

**추출 프롬프트를 `en2` 로 바꾼다.** 영어라서가 아니라 지시가 더 좋아서다.

원본에 없던 문장을 하나 더 넣었다.

```
this value is matched against the source text character by character,
and a reworded line is discarded
```

모델에게 **채점 방식을 알려주는** 문장이다. `evidence` 를 원문 그대로 옮겨야 할 동기가
생기고, 그래서 한국어 원본보다도 파라미터를 10개 더 뽑는다.

**선별 프롬프트는 손대지 않는다.** 같은 처방(대상 언어 명시 + 이유 보강)을 해봤으나
적중은 동등하거나 낮고 토큰만 12% 늘었다. 선별은 참/거짓 하나이고 이미 재현율 100%
라 설명을 늘려도 개선할 여지가 없다.

일반화하면 이렇다.

> 프롬프트에서 이유 설명과 예시는 장식이 아니라 **지시의 일부**다. 토큰을 아끼려고
> 걷어내면 준수율이 떨어진다. 단, 지시가 단순하고 이미 정확도가 천장에 닿아 있으면
> 이유를 더해도 얻을 게 없다.

## 결과

**좋아진 것**

| | 전 | 후 |
|---|---|---|
| 적중 | 22~23/24 | **24/24** |
| 적재 파라미터 | 143~156 | **173** |
| 추출 프롬프트 토큰 | 347 | **196** (−44%) |
| 문서당 입력 토큰 | 43,948 | 39,569 (−10%) |

- 3회 대조에서 `en2` 가 더 안정적이었다 (적중 23/23/23 vs 23/23/22).

**나빠진 것 / 감수하기로 한 것**

- **프롬프트 언어가 파일 안에서 섞인다.** 선별·추출은 영어, 식별은 한국어다.
  통일이 목적이 아니라 각 단계에서 재보고 이긴 쪽을 쓴 결과다.
- **식별 프롬프트는 재지 않았다.** 문서당 한 번뿐이라 토큰 영향이 미미하다.
- **문서 하나(SECUI MFD)로만 쟀다.** 영어 프롬프트가 한국어 문서에서 이만큼 나온다는
  건 확인했지만, 영문 문서(FortiOS 등)에서는 모른다.
- **`conf/ia-conf.xml` 의 `extract_prompt` 는 길이가 아니라 내용으로 유지해야 한다.**
  "군더더기" 처럼 보이는 이유 설명을 지우면 적중이 23에서 18로 떨어진다. 설정 파일에
  그 경고를 주석으로 달아 뒀다.

**되돌려야 할 신호**

- 영문 문서가 주류가 되면 프롬프트 언어를 다시 잰다. 지금 결론은 "한국어 문서 + 영어
  지시 + 이유 보강" 조합에 대한 것이다.
- 추출 규칙이 더 늘어 프롬프트가 다시 300토큰을 넘으면, 줄일 곳은 이유가 아니라
  **규칙 자체**다 — 안 지켜지는 규칙이 있는지 먼저 본다.
