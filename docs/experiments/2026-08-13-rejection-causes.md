# 반려 원인 분석 — 표 레이아웃 가설은 절반만 맞았다

- **날짜:** 2026-08-13
- **결론:** 저점수 문서의 반려는 세 갈래다. **(1) WAPPLES — 유실이 아니라 정당한
  조각 반려**: 필드 표 청크에 URL 이 없어 반려되지만 진짜 API 는 승인군에 다
  있다. **(2) pan-os — 변환 단계의 글리프 손상**: 원문 88%에서 리가처(ti/ft)가
  깨져 문자열 대조 자체가 불가능하다. 표 레이아웃이 아니라 PDF 폰트 문제다.
  **(3) 유해IP — JSON 예시가 표로 뭉개짐**: `<br>` 범벅 표 셀에서 근거 대조가
  안 된다. 승인 대기 67건은 82%가 "파라미터 이름은 전부 원문에 실재" —
  대부분 승인될 가능성이 높다.

## 방법

[재실측](2026-08-13-endpoint-scoring-revalidation.md) 데이터에서 저점수 문서 4개
(WAPPLES / pan-os / 유해IP / AXGATE)의 반려 전건을 채점기 로직으로 재분류했다 —
endpoint 부재 / endpoint 원문 불일치 / 파라미터 근거 불일치. 불일치 파라미터는
이름이 원문에 있는지(추출은 맞고 근거 문자열만 어긋남)를 추가로 봤다.

## 결과 1 — 반려의 주범은 파라미터가 아니라 endpoint 다

| 문서 | 반려 | endpoint 부재 | endpoint 불일치 | 파라미터 근거 |
|---|---|---|---|---|
| WAPPLES | 170 | 46 | **114** | 10 |
| pan-os | 108 | **49** | 46 | 13 |
| 유해IP | 63 | **33** | 24 | 6 |
| AXGATE | 52 | **38** | 6 | 8 |

endpoint 부재는 "요청 메시지 Header 포맷", "Response 포맷" 같은 공통 절 조각이
대부분 — 08-10 에서 조인 채점이 의도한 그대로다.

## 결과 2 — WAPPLES 반려는 유실이 아니다

불일치 표본을 열어 보면 전부 "Response fields" 표만 있는 청크다. WAPPLES 는
API 마다 URL 절과 필드 표 절이 분리돼 있고 표 절에는 URL 이 다시 안 나온다.
모델이 그 청크에서 `/users` 같은 endpoint 를 추측해 내지만 원문에 없으니 0점.

**그런데 승인군에 `/conf/users` 등 132개 endpoint 가 이미 있다** — URL 이 실재하는
청크에서 뽑힌 같은 API 들이다. 즉 반려된 것은 중복 조각이고, 적재는 온전하다.
평균 점수(49.6)가 낮아 보여도 손실이 아니다. 문서별 평균 점수는 품질 지표로
쓰면 안 된다는 뜻이기도 하다 — 조각 많은 문서일수록 낮게 나온다.

## 결과 3 — pan-os 는 표가 아니라 글리프가 문제다

추출 261건 중 **230건(88%)의 원문에 깨진 리가처**가 있다. PDF 폰트가 ti/ft 를
합자 글리프로 쓰는데 텍스트 레이어에서 사유 영역(U+E000)으로 오거나 아예
사라진다 — `Authentication` → `Authencaon`, `software` → `soware`.

LLM 은 깨진 원문을 읽고도 올바른 철자로 규격을 내므로(`software`), 채점의
문자열 대조가 어긋난다. 정규화로 못 고친다 — `soware` 는 글리프가 통째로
사라진 경우라 복원 정보가 없다. **변환 단계의 알려진 한계로 둔다.** 되돌릴
신호: 이런 폰트의 문서가 늘면 변환기에 폰트 글리프 매핑 보정을 검토한다.

## 결과 4 — 승인 대기 67건은 대부분 승인될 것으로 보인다

70~89점 대기 67건(pan-os 18, 유해IP 10, 나머지 산발) 중 **55건(82%)은 근거가
어긋난 파라미터조차 이름이 전부 원문에 실재**한다. 파라미터 자체는 표에 있고
evidence 문자열만 표 변환 형태와 어긋난 경우다 — 추출이 틀렸다기보다 근거
전사가 흔들린 것이다.

검토 UI 로 실제 승인률을 확인해 80% 이상이면 자동 임계값을 85 로 낮추는 것을
검토한다. 낮춰서 얻는 것은 대기 22건(85~89 구간)의 자동화다 — 검토량이 이미
작아 급하지 않다.

## 남은 것

- 승인 대기 67건을 UI 로 실제 검토 — 위 82% 추정의 실측 확인

