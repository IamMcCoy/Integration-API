# 실험

문서에 "아마 이럴 것이다" 라고 쓰고 싶어질 때, 그러지 말고 돌려보고 결과를 남기는 곳.

## 규칙

- **재현 방법을 반드시 포함한다.** 스크립트든 명령이든, 6개월 뒤에 다시 돌릴 수 있어야 한다.
- 가설 → 방법 → 결과 → 결론 순으로 쓴다.
- 결론이 "가설이 틀렸다" 여도 남긴다. 틀린 가설을 다시 세우지 않게 하는 게 목적이다.
